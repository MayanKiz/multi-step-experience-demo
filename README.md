# Multi-Step Experience Demo

A small browser-based interaction experiment that guides a visitor through a sequence of HTML screens, including a countdown, password step, and final experience.

## Tech Stack

- HTML
- CSS
- Vanilla JavaScript

## Run Locally

Serve the repository with any static web server:

```bash
python3 -m http.server 8000
```

Open `http://localhost:8000` and begin with `index.html`.

## Project Structure

- `index.html` — entry screen
- `countdown.html` — countdown step
- `password.html` — access step
- `final.html` — final experience
